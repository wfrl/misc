(*/section Natural deduction inference rules *)

hypo. (⊤ ∧ A ⊢ A), rule.
conj_intro. (H1 ⊢ A) → (H2 ⊢ B) → (H1 ∧ H2 ⊢ A ∧ B), rule.
conj_eliml. (H ⊢ A ∧ B) → (H ⊢ A), rule.
conj_elimr. (H ⊢ A ∧ B) → (H ⊢ B), rule.
disj_introl. (H ⊢ A) → (H ⊢ A ∨ B), rule.
disj_intror. (H ⊢ B) → (H ⊢ A ∨ B), rule.
disj_elim. (H1 ⊢ A ∨ B) → (H2 ∧ A ⊢ C) → (H3 ∧ B ⊢ C) →
  (H1 ∧ H2 ∧ H3 ⊢ C), rule.
subj_intro. (H ∧ A ⊢ B) → (H ⊢ A → B), rule.
subj_elim. (H1 ⊢ A → B) → (H2 ⊢ A) → (H1 ∧ H2 ⊢ B), rule.
neg_intro. (H ∧ A ⊢ ⊥) → (H ⊢ ¬A), rule.
neg_elim. (H1 ⊢ ¬A) → (H2 ⊢ A) → (H1 ∧ H2 ⊢ ⊥), rule.
equi_intro. (H1 ⊢ A → B) → (H2 ⊢ B → A) → (H1 ∧ H2 ⊢ A ↔ B), rule.
equi_eliml. (H ⊢ A ↔ B) → (H ⊢ A → B), rule.
equi_elimr. (H ⊢ A ↔ B) → (H ⊢ B → A), rule.
uq_intro. (nf u (H ∧ ∀x. Q x)) → (H ⊢ Q u) → (H ⊢ ∀x. Q x), rule.
uq_elim. (H ⊢ ∀x. Q x) → (H ⊢ Q t), rule.
ex_intro. (H ⊢ Q t) → (H ⊢ ∃x. Q x), rule.
ex_elim. (nf u (H1 ∧ H2 ∧ B ∧ ∃x. Q x)) →
  (H1 ⊢ ∃x. Q x) → (H2 ∧ Q u ⊢ B) → (H1 ∧ H2 ⊢ B), rule.


(*/section Axioms of classical propositional logic *)

efq. ⊢ ⊥ → A, axiom.
lem. ⊢ A ∨ ¬A, axiom.


(*/section Axioms of equality *)

eq_refl. ⊢ x = x, axiom.
eq_subst. ⊢ x = y → Q x → Q y, axiom.


(*/section Rule and axioms of modal logic KB *)

decl nec: Prop → Prop.
pos_equi. ⊢ ◇A ↔ ¬□¬A, def.

nec. (⊢ A) → (⊢ □A), rule.
K. ⊢ □(A → B) → □A → □B, axiom.
B. ⊢ A → □◇A, axiom.


(*/section Needed axioms of ZF set theory *)

decl Univ: Ind.
decl element: Ind → Ind → Prop.
decl comp: (Ind → Prop) → Ind. 

empty_set_eq. ⊢ ∅ = {x | x ∈ Univ ∧ ⊥}, def.
compl_eq. ⊢ compl A = {x | x ∈ Univ ∧ ¬(x ∈ A)}, def.

extensionality. ⊢ (∀x. x ∈ A ↔ x ∈ B) → A = B, axiom.
separation. ⊢ u ∈ {x | x ∈ A ∧ Q x} ↔ u ∈ A ∧ Q u, axiom.


(*/section Scott's variant of Gödel's axioms *)

decl P: Ind.
G_eq. ⊢ G = {x | x ∈ Univ ∧ ∀A. A ∈ P → x ∈ A}, def.
ess_equi. ⊢ ess E x ↔ x ∈ E ∧ ∀A. x ∈ A → □∀y. y ∈ E → y ∈ A, def.
NE_eq. ⊢ NE = {x | x ∈ Univ ∧ ∀E. ess E x → □∃y. y ∈ E}, def.

axiom_i. ⊢ A ∈ P ↔ ¬(compl A ∈ P), axiom.
axiom_ii. ⊢ A ∈ P → □(∀x. x ∈ A → x ∈ B) → B ∈ P, axiom.
axiom_iii. ⊢ G ∈ P, axiom.
axiom_iv. ⊢ A ∈ P → □(A ∈ P), axiom.
axiom_v. ⊢ NE ∈ P, axiom.

(*/note efq The principle <i>ex falso quodlibet</i>. From a contradiction,
any proposition follows. *)

(*/note lem The <i>law of excluded middle</i>. *)

(*/note eq_refl Reflexivity law of equality. *)

(*/note eq_subst Substitution principle of equality. *)

(*/note nec_decl The necessity `nec A`, which has the syntax
`□A`, is declared as a unary operation that maps propositions to
propositions. Its meaning is revealed by the axioms rather than
defined. *)

(*/note pos_equi Defines possibility `◇A` in terms of necessity as `¬□¬A`. *)

(*/note nec Necessitation rule of modal logic. *)

(*/note Univ_decl The universal set `Univ` is declared as an individual constant.
Rather than being defined, its role is revealed by the structure of the axioms. *)

(*/note element_decl The relation `element x A`, which has the syntax
`x ∈ A`, is declared as a binary predicate symbol. Its meaning is
revealed by the axioms rather than defined. *)

(*/note comp_decl The comprehension `comp Q`, which has the syntax
`{x | Q x}`, is declared as a unary second order function symbol. Its
meaning is revealed by the [[separation|axiom of separation]] rather
than defined. *)

(*/note compl_eq The <i>complement</i> of a set `A` is defined as the
set of elements not contained in `A`. *)

(*/note separation In this version of the <i>axiom of separation</i>, it is
already presupposed that the separated set is uniquely determined. For
this reason, no existence quantifier appears.  Otherwise, it would have
been stated as<br>
<br>
\_\_\_∃B. ∀u. u ∈ B ↔ u ∈ A ∧ Q u. *)

(*/note P_decl The set `P` of <i>positive properties</i> is declared as
an individual constant. Its meaning is revealed by the axioms rather
than defined. *)

(*/note G_eq An entity `x` is <i>God-like</i>, written `x ∈ G`,
by definition, if it has all [[P_decl|positive properties]]. *)

(*/note ess_equi By definition, `E` is an <i>essential</i> property of
entity `x` if `x` possesses this property `E` and `E` is necessarily
contained in every property `A` that `x` also possesses. *)

(*/note NE_eq An entity `x` has the property of <i>necessary existence</i>,
written `x ∈ NE`, by definition, if every [[ess_equi|essence]] `E` of `x`
is necessarily non-empty. *)

(*/note axiom_i A property `A` is [[P_decl|positive]] iff its
[[compl_eq|complement]] is not positive. That is, either is a
property `A` positive or its complement. *)

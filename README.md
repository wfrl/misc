
This monorepo contains smaller apps, CLI programs, tools, scripts, and records.

* `math/logic/` contains proof checkers.
* `proofs/` contains machine-assisted proof collections for logic, computer science, and mathematics.
* `music/` contains a MIDI visualizer, a few utility tools, and LilyPond templates.
* `templates/` contains templates for HTML, LaTeX, and Typst.

----

In diesem Monorepo finden sich kleinere Apps, CLI-Programme, Tools, Skripte und Aufzeichnungen.

* `math/logic/` enthält Beweisprüfer.
* `proofs/` enthält maschinengestützte Beweissammlungen zur Logik, Informatik und Mathematik.
* `music/` enthält einen MIDI-Visualisierer, ein paar Hilfswerkzeuge, und Vorlagen für LilyPond.
* `templates/` enthält Vorlagen für HTML, LaTeX und Typst.

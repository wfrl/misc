
# A derivation in intuitionistic sequent calculus.

hypo. verum ∧ H ⊢ H, rule.
wk. (H ⊢ B) → (H ∧ A ⊢ B), rule.
exch. (H ⊢ A) → (H ⊢ A), rule.

Rconj. (H1 ⊢ A) → (H2 ⊢ B) → (H1 ∧ H2 ⊢ A ∧ B), rule.
Rdisjl. (H ⊢ A) → (H ⊢ A ∨ B), rule.
Rdisjr. (H ⊢ B) → (H ⊢ A ∨ B), rule.
Rsubj. (H ∧ A ⊢ B) → (H ⊢ A → B), rule.
Rneg. (H ∧ A ⊢ ⊥) → (H ⊢ ¬A), rule.

Lconj. (H ∧ A ∧ B ⊢ C) → (H ∧ (A ∧ B) ⊢ C), rule.
Ldisj. (H1 ∧ A ⊢ C) → (H2 ∧ B ⊢ C) → (H1 ∧ H2 ∧ (A ∨ B) ⊢ C), rule.
Lsubj. (H1 ∧ (A → B) ⊢ A) → (H2 ∧ B ⊢ C) → (H1 ∧ H2 ∧ (A → B) ⊢ C), rule.
Lneg. (H1 ∧ ¬A ⊢ A) → (H2 ∧ ⊥ ⊢ C) → (H1 ∧ H2 ∧ ¬A ⊢ C), rule.

1. 1 ⊢ A, hypo.
2. 2 ⊢ A → B, hypo.
3. 1, 2 ⊢ A, wk 1.
4. 4 ⊢ B, hypo.
5. 5 ⊢ ¬B, hypo.
6. 4, 5 ⊢ B, wk 4.
7. 7 ⊢ ⊥, hypo.
8. 5, 4 ⊢ ⊥, Lneg 6 7.
9. 2, 5, 1 ⊢ ⊥, Lsubj 3 8.
10. 2, 5 ⊢ ¬A, Rneg 9.
11. 2 ⊢ ¬B → ¬A, Rsubj 10.
12. ⊢ (A → B) → (¬B → ¬A), Rsubj 11.

# A derivation in intuitionistic sequent calculus,
# without union of different contexts.

hypo. H ∧ A ⊢ A, rule.
wk. (H ⊢ B) → (H ∧ A ⊢ B), rule.
exch. (H ⊢ A) → (H ⊢ A), rule.

Rconj. (H ⊢ A) → (H ⊢ B) → (H ⊢ A ∧ B), rule.
Rdisjl. (H ⊢ A) → (H ⊢ A ∨ B), rule.
Rdisjr. (H ⊢ B) → (H ⊢ A ∨ B), rule.
Rsubj. (H ∧ A ⊢ B) → (H ⊢ A → B), rule.
Rneg. (H ∧ A ⊢ ⊥) → (H ⊢ ¬A), rule.

Lconj. (H ∧ A ∧ B ⊢ C) → (H ∧ (A ∧ B) ⊢ C), rule.
Ldisj. (H ∧ A ⊢ C) → (H ∧ B ⊢ C) → (H ∧ (A ∨ B) ⊢ C), rule.
Lsubj. (H ∧ (A → B) ⊢ A) → (H ∧ B ⊢ C) → (H ∧ (A → B) ⊢ C), rule.
Lneg. (H ∧ ¬A ⊢ A) → (H ∧ ⊥ ⊢ C) → (H ∧ ¬A ⊢ C), rule.

1. ¬B ∧ (A → B) ∧ A ⊢ A, hypo.
2. ¬B ∧ A ∧ (A → B) ⊢ A, exch 1.
3. A ∧ ¬B ∧ B ⊢ B, hypo.
4. A ∧ B ∧ ¬B ⊢ B, exch 3.
5. A ∧ B ∧ ⊥ ⊢ ⊥, hypo.
6. ¬B ∧ A ∧ B ⊢ ⊥, Lneg 4 5.
7. (A → B) ∧ ¬B ∧ A ⊢ ⊥, Lsubj 2 6.
8. (A → B) ∧ ¬B ⊢ ¬A, Rneg 7.
9. verum ∧ (A → B) ⊢ ¬B → ¬A, Rsubj 8.
10. ⊢ (A → B) → (¬B → ¬A), Rsubj 9.

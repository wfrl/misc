
### nd – a natural deduction proof checker

This program `nd` is a *proof checker* for the *natural deduction calculus*. It supports *minimal*, *intuitionistic*, *classical*, and *modal logic*, along with their respective *single-sorted first-order logics with a non-empty domain of discourse*. In addition to logic, concepts are needed to describe mathematical structures. For this purpose, an *axiomatic set theory* is typically used. Which specific set theory is used is not fixed, but is instead defined in the input through freely selectable axioms.

Further documentation is found in `doc/`, some basic examples in `examples/`.
